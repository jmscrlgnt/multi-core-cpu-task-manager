# Multi-Core CPU Task Manager

An interactive OS101 simulator for visualizing process scheduling and CPU resource allocation across multiple processor cores.

## Features

- Multi-core CPU simulation
- FCFS scheduling
- Shortest Job First (SJF)
- Priority scheduling
- Round Robin scheduling
- Configurable CPU cores
- Configurable Round Robin time quantum
- Process states
- Live CPU core visualization
- Gantt execution timeline
- Process performance metrics
- CPU utilization
- Average waiting time
- Average turnaround time
- Average response time
- Throughput

## Technologies

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone the repository.
2. Open `index.html` in a browser.
3. Configure the processes.
4. Select a scheduling algorithm.
5. Select the number of CPU cores.
6. Run the simulation.

## Project Purpose

This project was developed for OS101 to demonstrate concepts related to process management, CPU scheduling, multi-core CPU management, and simulation.

## Scheduling Algorithms

### FCFS
First Come, First Served scheduling.

### SJF
Shortest Job First scheduling.

### Priority
Processes with higher priority are selected first.

### Round Robin
Processes are scheduled using a configurable time quantum.
