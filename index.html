Implementation notes

How to Read the Simulator

FCFS

Processes are dispatched in arrival order whenever a core becomes free.

SJF

The shortest available job is selected first. This version is non-preemptive.

Priority

The available process with the lowest priority number is selected first.

Round Robin

Processes rotate through the ready queue after consuming their configured time quantum.

PROCESS → READY → SCHEDULER → CORE → EXECUTION → TERMINATED
